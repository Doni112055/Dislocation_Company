# 🚢 Система Дислокации и Мониторинга Контейнеров PRO (Корпоративная версия)

Полноценная корпоративная система учета дислокации контейнеров для совместной работы всей компании (логистов, диспетчеров, менеджеров и руководства).

---

## 🚀 Как запустить для всей компании

### 1. Компьютер-сервер (в офисе компании)
1. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   Дважды кликните по файлу `run_server.bat` или выполните:
   ```cmd
   python -m uvicorn server:app --host 0.0.0.0 --port 8000
   ```
3. Узнайте локальный IP-адрес этого компьютера (в командной строке выполните `ipconfig`, найдите строку `IPv4 Address`, например: `192.168.1.50`).

### 2. Подключение сотрудников компании

#### Вариант А: Через веб-браузер (без установки Python на ПК сотрудников)
Любой сотрудник в офисной сети (или через VPN) может открыть в Chrome, Edge или телефоне:
```
http://192.168.1.50:8000
```
*(где 192.168.1.50 — IP компьютера, где запущен сервер)*.
В браузере откроется точно такое же приложение: таблица, модальное окно добавления/редактирования, фильтры, Excel и графики.

#### Вариант Б: Через настольное приложение Windows (Десктоп)
1. Скопируйте папку с приложением на компьютер сотрудника.
2. Запустите `run_client.bat` (или `python client.py`).
3. При первом запуске или по кнопке **«⚙️ Сервер»** укажите IP-адрес: `http://192.168.1.50:8000`. Настройка сохранится автоматически.

## 📋 Состав полей карточки контейнера (Модальное окно «Данные контейнера»)
- **Номер** — номер контейнера (например: `TGHU1234567`)
- **Грузополучатель** — наименование клиента
- **Баржа** — выпадающий список (`Zarafshon`, `Surxon`, `O'zbekiston`, `Samarkand`, `Jizzax`, `Toshkent`...) + свободный ввод
- **Направление** — выпадающий список территорий:
  - Казахстан
  - Афганистан
  - Узбекистан
  - Таджикистан
  - Туркменистан
  - Кыргызстан
  - Россия
  - Китай
- **Статус** — `В пути`, `Задержан`, `Доставлен`, `Возвращен`, `Погрузка`
- **Причина** — причина задержки или комментарий
- **Дата отправки** — календарь (YYYY-MM-DD)
- **Дата возврата** — календарь (YYYY-MM-DD) или кнопка очистить
- **Количество дней** — рассчитывается автоматически на лету
- **Добавлен пользователем** — фиксирует автора записи
- **Кнопки**: `[💾 Сохранить]`, `[🗑 Удалить]`, `[📜 История]`

## 🔒 Исправленные критические ошибки исходных файлов:
1. **Восстановлены потерянные данные**: в `server.py` добавлены поля `client` (Грузополучатель) и `barge` (Баржа) в схемы БД и API.
2. **Исправлен адрес сети**: вместо невалидного `0.0.0.00:8000` реализована плавающая настройка IP с автосохранением в `client_config.json`.
3. **Единая база**: реестр контейнеров перенесен из изолированного локального файла `registry.csv` на сервер в общую БД SQLite в режиме высокой параллельности (`WAL mode`), что исключает блокировки базы данных при одновременной работе десятков сотрудников.
4. **Автоматическое обновление**: данные синхронизируются в реальном времени каждые 30 секунд.
